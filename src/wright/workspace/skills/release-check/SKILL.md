# 发布前检查

这是一份可复用的发布前核对流程。调用 skill 工具加载后按步骤执行。

## 步骤

1. 确认当前工作区没有未提交的调试代码或密钥。
2. 阅读相关测试文件，用 `execute_command` 跑与本次改动对应的测试，不要扩大范围乱跑。
3. 检查用户明确要求的验收项是否都有对应证据（测试、日志或命令输出）。
4. 把结论交回主任务：通过 / 不通过，以及未完成的项。

## 注意

- 不要把本流程写进长期记忆；它是做法，不是事实。
- `allowed_tools` 只是建议。当前会话的工具清单在启动时已经冻结，不会因为加载本 skill 而增减。
