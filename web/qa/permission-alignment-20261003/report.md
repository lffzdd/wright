# 权限工程与前端对齐

本次修改围绕现有领域策略、授权仓储和系统隔离实现，不新增界面层放行逻辑。旧版策略展示字段和失效选项文案已移除。

- 文件记忆按路径和操作授权，写入、编辑等文件工具可复用；保留精确文件、目录递归、只读和期限边界。跨工具复用、相邻文件拒绝和撤销失效都有后端回归。
- 策略页展示会话、项目、用户实际期限；展示通配文件工具规则、明确的工具限制和硬只读目录。
- Shell 未完成系统隔离时禁止按钮和快捷键批准，保留拒绝；提供初始化及失败重试。初始化本身不批准调用。
- 单次联网改变主按钮语义，禁用保存离线授权，防止静默丢失网络选项。
- 文件目标与内容预览分开，预览截断显式说明；风险来自后端描述，普通命令不再统一标为中风险。
- 保存或撤销采用服务端返回的状态；409 显示最新状态，保留清晰错误并要求查看后重试。
- 修复中英文文案、平台快捷键和窄屏阅读布局。权限文案及浏览器测试数据由后端生成，后端测试检查生成结果是否同步。
